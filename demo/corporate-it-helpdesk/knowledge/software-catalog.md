## Software Request Process

### Step 1: Check Availability
- Review software catalog
- Check if software is already available
- Verify license availability

### Step 2: Submit Request
- Go to IT portal
- Select "Software Request"
- Choose software from catalog or request new
- Provide business justification
- Select approval chain

### Step 3: Approval Process
- **Manager Approval**: Required for all requests
- **Budget Approval**: Required if cost > $100/month
- **Security Review**: Required for new/unlisted software
- **License Procurement**: IT handles after approval

### Step 4: Installation
- **Standard Software**: Self-service installation from portal
- **Specialized Software**: IT installs and configures
- **License Assignment**: Automatic after installation

## License Management

### License Types
- **Per-User**: Assigned to individual employee
- **Concurrent**: Shared pool (first-come, first-served)
- **Site License**: Unlimited use for department/location

### License Limits
- **Standard Software**: No limits
- **Premium Software**: Limited licenses available
- **Waitlist**: Automatic if licenses exhausted

### License Renewal
- **Annual Renewal**: IT handles automatically
- **Cancellation**: Submit request 30 days before renewal
- **Transfer**: Available when employee leaves

## Software Updates

### Automatic Updates
- **Windows Updates**: Managed by IT (deployed monthly)
- **Microsoft 365**: Automatic updates
- **Antivirus**: Automatic updates

### Manual Updates
- **Third-Party Software**: Check for updates monthly
- **Critical Updates**: IT pushes immediately
- **Feature Updates**: Scheduled quarterly

## Software Support

### Self-Service Resources
- **Knowledge Base**: Available in IT portal
- **Video Tutorials**: Available for common software
- **User Guides**: Available for all standard software

### IT Support
- **Standard Software**: Full support available
- **Specialized Software**: Basic support, may refer to vendor
- **Custom Software**: Limited support, contact development team

## Prohibited Software

### Not Allowed
- **Peer-to-Peer File Sharing**: BitTorrent, etc.
- **Unauthorized Cloud Storage**: Personal Dropbox, Google Drive for work files
- **Unapproved VPNs**: Personal VPN services
- **Gaming Software**: Not allowed on company devices
- **Cryptocurrency Mining**: Prohibited

### Consequences
- **Warning**: First violation
- **Disciplinary Action**: Repeated violations
- **Termination**: Serious security violations
