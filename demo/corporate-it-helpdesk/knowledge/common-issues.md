# Common IT Issues & Solutions

## Password & Account Issues

### Password Reset
- **Self-Service Portal**: Available 24/7 at password.company.com
- **Process**: 
  1. Enter employee ID or email
  2. Answer security questions or use mobile authenticator
  3. Set new password (must meet complexity requirements)
- **Requirements**: 
  - Minimum 12 characters
  - Mix of uppercase, lowercase, numbers, special characters
  - Cannot reuse last 5 passwords
- **Locked Account**: Unlocks automatically after 30 minutes, or contact IT support

### Multi-Factor Authentication (MFA)
- **Required For**: All employees
- **Methods**: 
  - Mobile authenticator app (recommended)
  - SMS codes
  - Hardware token (for special cases)
- **Setup**: Available in employee portal under Security settings
- **Issues**: Contact IT if authenticator not working

### Account Access Issues
- **New Employee Setup**: IT creates account within 24 hours of HR onboarding
- **Access Delays**: Contact IT support with employee ID
- **Terminated Employees**: Access revoked immediately by HR/IT

## Software & Applications

### Standard Software
- **Office Suite**: Microsoft 365 (Word, Excel, PowerPoint, Teams)
- **Email**: Outlook (desktop and web)
- **Collaboration**: Teams, Slack, SharePoint
- **VPN**: Required for remote access
- **Antivirus**: Company-managed endpoint protection

### Software Installation Requests
- **Standard Software**: Available through company software portal (self-service)
- **Non-Standard Software**: 
  - Submit request through IT portal
  - Requires manager approval
  - Security review (3-5 business days)
  - License procurement (5-10 business days)
- **Free Software**: Still requires IT approval for security review

### Software Issues
- **Won't Launch**: 
  1. Restart computer
  2. Check if software is installed (Control Panel/Applications)
  3. Reinstall from software portal
  4. Contact IT if issue persists

- **Slow Performance**:
  - Check available disk space (need 10% free minimum)
  - Close unnecessary applications
  - Restart computer
  - Check for updates

- **Licensing Errors**:
  - Sign out and back into software
  - Contact IT for license reassignment

## Hardware Support

### Laptop Issues
- **Won't Start**: 
  - Check power adapter connection
  - Try different power outlet
  - Hold power button for 10 seconds (hard reset)
  - Contact IT for hardware replacement

- **Slow Performance**:
  - Restart computer
  - Check for Windows/Mac updates
  - Run disk cleanup
  - Check available storage space

- **Display Issues**:
  - Check display cable connections
  - Try different display port
  - Update graphics drivers
  - Contact IT for hardware check

### Peripherals
- **Printers**: 
  - Network printers: Auto-configured on company network
  - Local printers: Submit IT request for driver installation
  - Printing issues: Check printer queue, restart print spooler service

- **Monitors**:
  - Standard: One monitor provided
  - Additional monitors: Submit IT request (manager approval required)
  - Setup: IT can assist with configuration

- **Keyboards/Mice**:
  - Standard equipment provided
  - Ergonomic options: Available through IT request
  - Wireless devices: Company-approved models only

## Network & Connectivity

### Wi-Fi Access
- **Office Wi-Fi**: 
  - Network: Company-Guest (for visitors)
  - Network: Company-Secure (for employees, requires domain credentials)
  - Password: Not required for secure network (uses domain authentication)

### VPN Access
- **Required For**: Remote access to company resources
- **Setup**: 
  1. Download VPN client from IT portal
  2. Install and configure with provided credentials
  3. Connect before accessing company resources
- **Issues**: 
  - Check internet connection
  - Verify credentials
  - Restart VPN client
  - Contact IT if connection fails

### Internet Issues
- **Slow Connection**: 
  - Check if other users experiencing same issue
  - Restart router/modem
  - Check for network maintenance notifications
  - Contact IT if widespread issue

## Email & Communication

### Email Issues
- **Can't Send Email**: 
  - Check internet connection
  - Verify email address format
  - Check for large attachments (25MB limit)
  - Check if account is locked

- **Can't Receive Email**:
  - Check spam/junk folder
  - Verify email address
  - Check storage quota (50GB limit)
  - Contact IT if issue persists

### Teams/Slack Issues
- **Can't Connect**: 
  - Check internet connection
  - Sign out and back in
  - Update application
  - Restart computer

- **Audio/Video Issues**:
  - Check device permissions
  - Test microphone/speakers in system settings
  - Update drivers
  - Try different device

## Security

### Phishing & Security
- **Suspicious Emails**: 
  - Don't click links or download attachments
  - Forward to security@company.com
  - Delete email
  - Report through security portal

- **Malware/Virus**:
  - Don't ignore antivirus warnings
  - Run full system scan
  - Contact IT immediately if infected
  - Don't disconnect from network

### Data Protection
- **File Sharing**: 
  - Use company-approved cloud storage (OneDrive, SharePoint)
  - Don't use personal cloud services for work files
  - Encrypt sensitive data before sharing

- **Backup**: 
  - Important files automatically backed up to OneDrive
  - Local files: Use OneDrive sync
  - Don't store sensitive data on local drive only

### How to Submit
- **Portal**: Available at it.company.com
- **Categories**:

  - Software requests
  - Access requests
  - Technical support
  - Account issues

- **Status Updates**: Sent via email
- **Portal**: Check ticket status anytime

## IT Policies

### Bring Your Own Device (BYOD)
- **Allowed**: With IT approval and security configuration
- **Requirements**: 
  - Company mobile device management (MDM) installed
  - Security policies enforced
  - Regular security updates required

### Software Downloads
- **Prohibited**: 
  - Unauthorized software
  - Peer-to-peer file sharing
  - Personal cloud storage for work files
  - Unapproved browser extensions

### Data Usage
- **Monitoring**: Company monitors network usage for security
- **Limits**: Reasonable use policy applies
- **Prohibited**: Streaming, gaming, excessive personal use
